Approval attribution — measured, not assumed

Every high-stakes act here is human-approved, so who approved it is part of the evidence a dispute turns on. This section walks each register the commit actually wrote to and reports whether the approver survived. Measured on this store: :careplan/set and :fibre-screening/set persist the proposal :payload (so the approver survives), while :ticket/mark-cleaned and :ticket/mark-returned are keyed off path only and drop it. Separately, the :approval-granted fact is written to the run's audit channel but never appended to the store ledger, so for the two actuations the approver is recoverable only from the audit trail. The lookup below is derived at render time — if the store is fixed, this page corrects itself.
